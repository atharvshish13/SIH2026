🔌 Connect ESP32 readingsHTTP JSON

Connect an ESP32 over Wi-Fi and point this dashboard to its sensor endpoint. The device should return rainfall, soil moisture, tilt, and temperature readings.

Demo values are active. Connect a device to replace them with live readings.

Wire the sensorsConnect FC-37 to an analog pin, capacitive soil sensor to an analog pin, MPU6050 over I2C, and DHT22 to a digital pin.
Join the networkPut the ESP32 and this dashboard on the same Wi-Fi network. Find the board IP from the serial monitor or router.
Expose a JSON endpointServe /sensors from the ESP32 and allow browser requests with CORS.
{"rainfall":245,"soilMoisture":78,"tilt":32,"temperature":22.4}
